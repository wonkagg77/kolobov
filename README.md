# Training Planner

**Автор:** Данил Колобов

## Описание
GUI-приложение для планирования тренировок. Позволяет добавлять, фильтровать и сохранять тренировки в JSON-файл.

## Требования
- Python 3.6+
- Tkinter (стандартная библиотека)

## Использование
1. Установите Python.
2. Скачайте файлы проекта.
3. Запустите: `python training_planner.py`
4. Добавьте тренировку через форму.
5. Используйте фильтрацию по типу и дате.
6. Данные сохраняются в `trainings.json`.

## Примеры использования
- Добавьте тренировку: дата — 2026-05-05, тип — «Кардио», длительность — 60.
- Примените фильтр по типу «Кардио».
- Сбросьте фильтр.
